# 치킨왕: 오늘도 튀긴다!

React + TypeScript + Vite로 만든 PC·모바일 요리 게임입니다. 치킨은 직접 생성한 사진풍 투명 이미지, 주방은 SVG·CSS, 소리는 Web Audio를 사용합니다. 이미지 자산은 게임과 함께 제공되며 플레이할 때 유료 API가 필요 없습니다. 이미지 로딩 실패 시 코드로 만든 SVG 치킨으로 대체됩니다. 폰트 다운로드에 실패하면 시스템 글꼴을 사용합니다.

## 실행
Node.js 22 이상 권장.

```sh
npm ci
npm run dev
```

## 검증
```sh
npm test
npm run build
```

손님이 후라이드·양념·간장 중 하나를 랜덤으로 주문합니다. 주문 카드의 메뉴를 확인하고 그에 맞게 조리하세요. 메뉴를 직접 바꾸거나 해금할 필요가 없습니다. 닭 → 튀김옷을 클릭하고 치킨을 둥근 기름솥으로 드래그하세요. 치킨은 넉넉한 기름 아래에 잠기며 위로 기포와 파문이 올라옵니다. 모바일에서도 터치 드래그를 지원하며 집게 버튼으로도 이동할 수 있습니다. 175℃에서 기본 후라이드는 약 12초 후 완벽한 상태가 됩니다. 양념치킨은 약 13초, 간장치킨은 약 14초가 적당합니다. 속 익힘 100%를 확인하고 집게로 건진 뒤 접시를 눌러 제공하세요. 종류마다 조리 시간이 달라지며 30초 안에 주문을 완료해야 합니다. 주문을 받으면 대기 시간이 바로 흐릅니다. 튜토리얼과 업그레이드 화면에서는 조리가 일시 정지됩니다.

저온 조리는 눅눅함, 고온 조리는 빠른 겉 탄화를 유발합니다. 속이 덜 익거나 탄 치킨은 판매할 수 없습니다. 성공 콤보는 보상을 늘리고 완벽한 치킨은 추가 보상을 받습니다. 지갑, 누적 매출, 최고 콤보, 기름솥·기름 업그레이드는 로컬 저장소에 보관됩니다. 매출은 브라우저의 현지 날짜를 기준으로 매일 초기화되며 지갑과 점수, 업그레이드는 유지됩니다. 데이터는 해당 브라우저에만 저장되며 비공개 모드나 저장소 삭제 시 사라질 수 있습니다.

기름솥 업그레이드는 주문 대기 시간 +3초, 좋은 기름은 수익 +10%를 제공합니다. 메뉴는 후라이드·양념·간장 세 종류로 고정되며 처음부터 모두 주문됩니다. 치킨 종류 해금이나 매운 치킨 메뉴는 없습니다. 어떤 주문에도 양념·간장 소스가 항상 보입니다. 치킨을 건진 뒤 후라이드 그대로·양념·간장 중 원하는 마무리를 직접 선택할 수 있습니다. 양념·간장 주문은 해당 소스를 선택해 버무려야 합니다. 치킨 위를 마우스나 손가락으로 문지르거나 버무리기 버튼을 세 번 눌러 소스를 100% 입힌 후 제공하세요. 소스를 덜 묻힌 주문은 완료할 수 없습니다. 후라이드에 소스를 입히거나 주문과 다른 소스로 제공하면 보상 없이 실패합니다. 한 번 입히기 시작한 소스는 바꿀 수 없으며, 소스를 선택만 하고 아직 입히지 않았으면 바꿀 수 있습니다. 소스를 입혀도 덜 익거나 탄 치킨은 실패합니다. 기존 플레이어의 돈·점수·기록·장비는 유지되며 이전 레시피 해금 필드는 더 이상 사용하지 않습니다. 음향은 사용자 입력 후 활성화되며 사운드 버튼으로 끌 수 있습니다. 진동은 지원 브라우저에서만 작동합니다.

게임 계산은 `src/engine.ts`, 조작·렌더링은 `src/main.tsx`에 분리되어 있습니다. 외부 서버·인증 정보가 필요 없습니다.

## 공개 링크 배포

GitHub Pages 무료 정적 호스팅을 위한 `.github/workflows/pages.yml`을 포함합니다.

1. 저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
2. **Actions → Publish Chicken King → Run workflow → main**을 실행합니다. 이후 `main` 푸시 시 테스트·빌드·배포가 자동 실행됩니다.
3. 성공 후 Pages 설정에 표시되는 공개 URL을 공유합니다. 현재 저장소의 예상 주소는 `https://cocolove1541-sketch.github.io/-/`입니다. 배포 성공 전에는 공개된 링크로 간주하지 마세요.

다른 정적 호스팅에도 `npm ci && npm run build` 후 `dist/`의 내용을 올리면 됩니다. 상대 에셋 경로를 사용하여 프로젝트 하위 경로에서도 실행됩니다. `dist/`에 비밀 키나 서버 환경 변수는 포함하지 않습니다.

## 치킨 이미지

`src/assets/chicken-atlas.png`는 이 게임을 위해 생성한 원본 자산입니다. 두툼하고 울퉁불퉁한 튀김옷의 질감을 참고한 사진풍 이미지로, KFC 제품 사진이나 로고를 사용하지 않습니다. 생닭·튀김옷·후라이드·양념·간장·탄 치킨 6개 프레임을 CSS로 표시하며, 조리·소스 진행도에 따라 프레임을 혼합합니다. 이미지는 한 번 로드하여 모든 치킨에 재사용하고 실패 시 SVG로 대체합니다.

## 세 친구 손님

사용자가 제공한 이미지의 파란 귀 친구 → 토끼 친구 → 하얀 친구 순서로 방문하며 이후 같은 순서를 반복합니다. 주문 종류는 손님 외형과 별개로 랜덤입니다. `src/assets/customer-atlas.png`에는 평상시·화난 표정이 들어 있습니다. 남은 시간이 짧아지면 초조한 대사, 제한 시간 초과 시 화난 표정·흔들림·항의 대사가 나타나고 주문이 실패합니다. 모바일에서는 화난 손님 카드로 이동하여 표정을 확인할 수 있습니다. 다음 주문을 누르면 다음 친구가 정상 표정으로 방문합니다. 이미지 로드가 실패해도 SVG 대체 캐릭터와 핵심 게임은 작동합니다.
