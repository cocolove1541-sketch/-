# 치킨왕: 오늘도 튀긴다!

React + TypeScript + Vite로 만든 PC·모바일 요리 게임입니다. 그래픽은 직접 만든 SVG·CSS, 소리는 Web Audio로 생성하며 유료 API나 이미지 다운로드가 필요 없습니다. 폰트 다운로드에 실패하면 시스템 글꼴을 사용합니다.

## 실행
Node.js 22 이상 권장.

```sh
npm ci
npm run dev
```

## 검증
```sh
npm test
npm run build
```

닭 → 튀김옷을 클릭하고 치킨을 튀김기로 드래그하세요. 모바일에서도 터치 드래그를 지원하며 집게 버튼으로도 이동할 수 있습니다. 175℃에서 기본 후라이드는 약 12초 후 완벽한 상태가 됩니다. 속 익힘 100%를 확인하고 집게로 건진 뒤 접시를 눌러 제공하세요. 종류마다 조리 시간이 달라지며 30초 안에 주문을 완료해야 합니다. 처음 준비를 시작할 때 주문 시간이 흐릅니다.

저온 조리는 눅눅함, 고온 조리는 빠른 겉 탄화를 유발합니다. 속이 덜 익거나 탄 치킨은 판매할 수 없습니다. 성공 콤보는 보상을 늘리고 완벽한 치킨은 추가 보상을 받습니다. 지갑, 누적 매출, 최고 콤보, 튀김기·기름·레시피 업그레이드는 로컬 저장소에 보관됩니다. 매출은 브라우저의 현지 날짜를 기준으로 매일 초기화되며 지갑과 점수, 업그레이드는 유지됩니다. 데이터는 해당 브라우저에만 저장되며 비공개 모드나 저장소 삭제 시 사라질 수 있습니다.

튀김기 업그레이드는 주문 대기 시간 +3초, 기름은 수익 +10%, 레시피는 양념·간장·매운 치킨 주문과 추가 보상을 해금합니다. 소스 제조는 별도 단계 없이 주문 레시피에 적용됩니다. 음향은 사용자 입력 후 활성화되며 사운드 버튼으로 끌 수 있습니다. 진동은 지원 브라우저에서만 작동합니다.

게임 계산은 `src/engine.ts`, 조작·렌더링은 `src/main.tsx`에 분리되어 있습니다. 외부 서버·인증 정보가 필요 없습니다.

## 공개 링크 배포

GitHub Pages 무료 정적 호스팅을 위한 `.github/workflows/pages.yml`을 포함합니다.

1. 저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
2. **Actions → Publish Chicken King → Run workflow → main**을 실행합니다. 이후 `main` 푸시 시 테스트·빌드·배포가 자동 실행됩니다.
3. 성공 후 Pages 설정에 표시되는 공개 URL을 공유합니다. 현재 저장소의 예상 주소는 `https://cocolove1541-sketch.github.io/-/`입니다. 배포 성공 전에는 공개된 링크로 간주하지 마세요.

다른 정적 호스팅에도 `npm ci && npm run build` 후 `dist/`의 내용을 올리면 됩니다. 상대 에셋 경로를 사용하여 프로젝트 하위 경로에서도 실행됩니다. `dist/`에 비밀 키나 서버 환경 변수는 포함하지 않습니다.
